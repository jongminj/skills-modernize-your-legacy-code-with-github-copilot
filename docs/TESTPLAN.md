# Account Management System Test Plan

이 계획은 현재 COBOL 프로그램의 단일 계좌 업무와 구현 동작을 기준으로 작성했습니다. 테스트를 시작하기 전 별도 프로세스로 앱을 실행해 초기 잔액을 확인하고, 한 테스트 안의 단계는 같은 실행에서 수행합니다. `Actual Result`는 실행 중 관찰한 결과를 기록하고, `Status (Pass/Fail)`는 실행 전 `미실행`, 실행 후 `Pass` 또는 `Fail`로 갱신합니다.

잔액과 거래 금액은 `PIC 9(6)V99`이므로 논리상 소수 둘째 자리, 최대 999,999.99의 부호 없는 숫자입니다. 화면에는 이 필드를 편집하지 않고 그대로 표시하므로 소수점이 표시되지 않을 수 있습니다. 금액 비교는 논리적 금액을 기준으로 하고, 실제 화면 문자열도 `Actual Result`에 남겨 Node.js 이행 시 표시 호환 여부를 결정합니다. 금액 입력 검증 및 필드 초과 시 동작은 코드에서 정의하지 않으므로 특성화 케이스로 기록하고 업무 담당자와 기대 정책을 합의합니다.
